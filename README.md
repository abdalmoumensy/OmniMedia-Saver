# OmniMedia Saver (Desktop & Mobile) | برنامج تحميل الوسائط للكمبيوتر والهاتف

An all-in-one, dark-mode media downloader for **Windows PC** and **Android Mobile**, powered by `yt-dlp`.

تطبيق شامل بواجهة داكنة (Dark Mode) لتحميل الفيديوهات والصوتيات بجودات متعددة، متاح لأجهزة **الكمبيوتر (Windows)** و**الهاتف (Android)**، ويعمل بمحرك `yt-dlp`.

---

## 🇬🇧 English Guide

### Features
- **Multi-Quality Support:** Download in Best Quality, 1080p, 720p, 480p, or Audio-only (MP3 / M4A).
- **Cross-Platform:** Available for both Windows Desktop (Installer & Portable `.exe`) and Android smartphones (`.apk`).
- **Modern Dark UI:** Smooth circular progress ring, real-time speed/size/ETA stats, and activity log.
- **Privacy Clean:** No tracking, no ads, and zero personal data collection.

### How to Download & Install

Go to the **[Releases](../../releases)** page of this repository and download the file that matches your device:

| Platform / Version | File Name | How to Use |
| :--- | :--- | :--- |
| **Windows (Installer)** | `OmniMedia-Saver-Setup.exe` | Run the installer to add OmniMedia Saver to your Start Menu and Desktop. |
| **Windows (Portable)** | `OmniMedia-Saver-Portable.exe` | No installation needed—double-click to run directly from any folder or USB drive. |
| **Android (Mobile APK)** | `OmniMedia-Saver-Android.apk` | Download on your phone, tap the `.apk` file, and allow installation from unknown sources if prompted. |

### Running from Source Code
- **Desktop:** `pip install customtkinter yt-dlp imageio-ffmpeg && python omnimedia_saver.py`
- **Mobile (Kivy):** `pip install kivy yt-dlp && python main.py`

## 🇸🇦 الدليل باللغة العربية

### مميزات التطبيق
- **دعم جودات متعددة:** تحميل بأعلى جودة متاحة (Best)، أو بدقة `1080p`، `720p`، `480p`، أو تحميل الصوت فقط (`MP3` / `M4A`).
- **متاح للكمبيوتر والهاتف:** يعمل على نظام ويندوز (نسخة تثبيت + نسخة محمولة) وعلى هواتف أندرويد (`APK`).
- **واجهة داكنة عصرية:** حلقة تقدم دائرية متحركة مع عرض مباشر لحجم الملف وسرعة التحميل والوقت المتبقي.
